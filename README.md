### Featured Work

#### [Visual Reference App & Pipeline](https://github.com/therealfullmetal55555/visual-reference-pipeline)
Desktop workspace and automated pipeline for curating, organizing, and analyzing visual references.
- **Workspace App:** Offline-first desktop web app with an infinite canvas board, non-destructive image adjustments (brightness, contrast, grain, cropping), collage studio, and photo editor with typography overlays.
- **Media Engine:** Built-in streaming player for video and audio (up to 512 MB) with HTTP 206 Range requests and SQLite persistence.
- **Connectors:** Harvesters for Are.na and Pinterest (with 1200px CDN upscaling), Instagram archiving, and procedural layouts for Figma.
- *Stack: Python, Vanilla JavaScript, SQLite, Canvas API, macOS .app / DMG packaging*

#### [ZAUM Demo](https://github.com/therealfullmetal55555/zaum-demo) · [Live Demo ↗](https://therealfullmetal55555.github.io/zaum-demo/)
Interactive workspace for tracking blogger ad placements and campaign metrics.
- **Features:** Real-time search by blogger alias or SKU, filters by social platform and collaboration type, dynamic CPM calculation, and in-browser state persistence via `localStorage`.
- *Stack: Semantic HTML5, CSS3, Vanilla JS, GitHub Pages*

#### [MILLY FX PRO](https://github.com/therealfullmetal55555/millyfx-pro)
After Effects CEP extension and standalone ScriptUI toolkit for stylized video editing workflows.
- **Features:** Procedural FLIR thermal heatmaps, bass-reactive camera shake expressions, chromatic aberration, halation, and one-click compound effect stacks for music videos and editorial pacing.
- **Environment:** Tested on macOS with Adobe After Effects 2026.
- *Stack: ExtendScript (JSX), Adobe CEP, HTML5/CSS3*

#### [n8n-lint](https://github.com/therealfullmetal55555/n8n-lint)
Static security linter for n8n workflows with zero runtime dependencies.
- **Features:** 12 security rules detecting ungated writes after LLM nodes, open webhook vectors, exposed credentials, and eval injection in code nodes. Outputs SARIF for GitHub Code Scanning.
- **Verification:** 72 automated tests (100% pass), CLI, browser playground bundle.
- *Stack: Node.js (zero dependencies), GitHub Actions, SARIF*
